# Code of Conduct

This proposed code applies once public contribution opens. Participants are expected to be respectful, specific, evidence-based and protective of privacy. Harassment, discrimination, threats, disclosure of private information, malicious security activity and misrepresentation of test or benchmark results are unacceptable.

Until a public enforcement contact is published, concerns should be raised privately with the project owner, KRE Solution Engineering. Enforcement decisions rest with the project owner and must respect applicable law and due process.
