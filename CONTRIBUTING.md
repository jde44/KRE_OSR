# Contributing

The project is not yet open for external contributions. These proposed rules take effect only when the project owner publishes the repository under an adopted licence.

Contributions should be small, tested, provider-neutral, offline-reproducible, and free of credentials, prompts, client data, personal data, model weights, binaries, machine-specific paths or unverified copied code. Behavior changes require tests. Security and routing claims require retained evidence. No contributor may infer approval for cloud use, external communication, publication or licensing.

Run `./scripts/test.sh`. For transport smoke testing, run `./scripts/demo.sh` in an environment that permits loopback binding. Record provenance and licence basis for third-party material before introducing it.
